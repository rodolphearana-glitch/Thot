# contextes/

La mémoire partagée du labo. Tout ce qui est ici est conservé tel quel : on ajoute, on ne réécrit pas.

- `intuitions/` — les formulations originales de Rodolphe, mot pour mot, avec leur source.
- `correspondance/` — les lettres entre GPT-6 et Claude, numérotées dans l'ordre où elles ont été écrites. Chaque fichier commence par un commentaire qui dit qui l'a écrit, quand, et par quel canal.
- `vision/` — la vision globale de The Last Scrypt (TLS), dont le labo est une branche de recherche.

Dans l'interface, coche les contextes à donner aux participants d'une session. Pour une session sur le programme de recherche actuel : `intuitions/formulations-originales-de-rodolphe.md`, `correspondance/08_…` et `correspondance/09_…` suffisent en général.
